¿Qué viene después? Guía para seguir explorando

¡Felicidades por llegar al final de las 7 clases del taller! Ya dominas los pilares del live coding en Strudel: ritmos con mini-notation, armonía con escalas y acordes, efectos y envolventes ADSR, corte de samples, síntesis sustractiva/FM, recursos de Ear Candy y modulación con LFOs.

Pero Strudel es un lenguaje vivo y enorme. Esta página reúne las herramientas más entretenidas para que sigas experimentando por tu cuenta: desde cómo hacer que el computador improvise contigo mediante azar y cómo inventar tus propias funciones, hasta dónde hacer preguntas en el foro oficial de la comunidad.

1. Randomización, Probabilidad y Música Generativa

Uno de los mayores poderes del live coding frente a un DAW tradicional es que no necesitas dibujar cada variación a mano: puedes darle reglas de probabilidad a tu código para que el patrón evolucione solo y nunca suene exactamente igual dos veces.

1.1. Azar dentro de la Mini-Notation (? y |)

Sin salir de las comillas de la mini-notation, tienes dos operadores de azar inmediatos:

  • ? (Moneda al aire): Si pones un signo de interrogación después de un evento, tiene un 50% de probabilidad de sonar o quedarse en silencio. Puedes especificar la probabilidad exacta entre 0 y 1 escribiendo, por ejemplo, hh?0.2 (20% de probabilidad de eliminarse).
  • | (Elección aleatoria): Dentro de corchetes [a | b | c], Strudel elige una sola opción al azar en cada ciclo.
// El hi-hat y las notas fantasma de caja cambian en cada vuelta
// El último tiempo elige al azar entre clap (cp), rimshot (rim) o crash (cr)
s("bd [~ sd?0.4] [hh*4?] [cp | rim | cr]")
  .bank("RolandTR909")

1.2. Señales aleatorias continuas (rand, irand, perlin)

Cuando quieres que un parámetro numérico (como la nota de una escala, el corte del filtro .lpf() o el paneo .pan()) cambie de forma aleatoria o suave:

  • rand: Genera un número decimal aleatorio entre 0 y 1 en cada evento. Usa rand.range(min, max) para escalarlo.
  • irand(n): Genera un número entero aleatorio entre 0 y n - 1. ¡Es perfecto para elegir grados de una escala con n(irand(8)).scale("C:minor") o elegir variaciones de un sample!
  • perlin: Genera ruido Perlin entre 0 y 1. A diferencia de rand (que salta bruscamente), perlin se mueve como una ola suave e impredecible.
// Melodía generativa infinita en Do menor pentatónica
// irand(8) elige grados de la escala al azar y perlin mueve el filtro suavemente
n(irand(8).segment(8))
  .scale("C4:minor:pentatonic")
  .s("sawtooth")
  .lpf(perlin.range(300, 3200))
  .lpq(4)
  .pan(rand.range(0.2, 0.8))
  .delay(0.4).delaytime(1/8)
  .room(0.4)

1.3. Modificadores probabilísticos (sometimes, often, rarely, degradeBy)

También puedes aplicar una transformación o efecto solo algunas veces usando la familia de funciones sometimes:

FunciónProbabilidad¿Qué hace?Ejemplo
.always(fn)100%Aplica la función siempre.always(x => x.lpf(800))
.almostAlways(fn)90%Casi siempre aplica la función.almostAlways(x => x.gain(0.8))
.often(fn)75%Aplica la función frecuentemente.often(x => x.ply(2))
.sometimes(fn)50%Aplica la función la mitad de las veces.sometimes(x => x.fast(2))
.sometimesBy(p, fn)p (0 a 1)Tú defines la probabilidad exacta p.sometimesBy(0.3, x => x.rev())
.rarely(fn)25%Aplica la función de vez en cuando.rarely(x => x.crush(4))
.almostNever(fn)10%Sorpresa ocasional (1 de cada 10 eventos).almostNever(x => x.speed(-1))
.someCycles(fn)50% por cicloDecide por ciclo entero en vez de nota por nota.someCycles(x => x.jux(rev))
.degradeBy(p)p (0 a 1)Silencia aleatoriamente el porcentaje p de notas.degradeBy(0.35)
 
// Un patrón de batería que improvisa fills y efectos por sí solo
s("bd sd [~ bd] sd, hh*8")
  .bank("RolandTR808")
  .sometimes(x => x.ply(2))          // 50%: redobla el golpe
  .rarely(x => x.speed(0.5).crush(5)) // 25%: baja el pitch y bitcrushea
  .someCycles(x => x.fast(2))         // En algunos ciclos duplica la velocidad

2. Crear tus Propias Funciones y Efectos

Como Strudel está construido directamente sobre JavaScript, no estás limitado a las funciones que vienen de fábrica. Puedes crear tus propios atajos, sintetizadores personalizados o efectos encadenables para tocar mucho más rápido en vivo.

2.1. Guardar efectos y cadenas en funciones de JavaScript

Si notas que siempre escribes la misma combinación de efectos (por ejemplo, un filtro ácido, o un delay dub con reverb), puedes guardarla en una constante con la sintaxis flecha const miFuncion = x => ...: 

// Definimos dos funciones propias reutilizables:
const dubEcho = x => x.delay(0.55).delaytime(3/16).delayfeedback(0.65).room(0.5)
const acidEnv = x => x.s("sawtooth").lpf(400).lpq(12).lpenv(4).lpd(0.18)

// Ahora las aplicamos a cualquier patrón de forma limpia:
stack(
  s("bd ~ [~ bd] ~, ~ cp").bank("RolandTR909"),
  dubEcho(s("rim*4").degradeBy(0.5)),
  acidEnv(note("c2 c3 eb2 [g2 bb1]*2"))
)

2.2. Crear tus propios comandos encadenables con register()

¿Quieres que tu función se pueda encadenar con un punto (.miEfecto()) igual que los comandos nativos de Strudel? Usa register('nombre', (parametro, patron) => ...): 

// 1. Registramos un efecto propio llamado .acid(frecuencia)
register('acid', (cutoff, pat) =>
  pat.s("sawtooth").lpf(cutoff).lpq(14).lpenv(3.5).lpd(0.15).distort(1.5)
)

// 2. Registramos un "humanizador" que varía el volumen y paneo al azar
register('human', (amt, pat) =>
  pat.gain(rand.range(1 - amt, 1)).pan(rand.range(0.5 - amt, 0.5 + amt))
)

// ¡Ahora podemos usar .acid() y .human() como si fueran parte oficial de Strudel!
note("c2 [eb2 c3] g1 [bb1 c2]")
  .acid("<300 600 900 450>")
  .human(0.25)

3. Estructurar Canciones Completas (arrange y variables)

Cuando quieras pasar de un loop que se repite a una canción completa con Introducción, Verso, Coro/Drop y Outro, puedes guardar cada pista o sección en variables de JavaScript y ordenarlas en el tiempo con arrange([ciclos, patron], ...): 

// Definimos nuestros bloques musicales en constantes:
const drumsSuave = s("bd ~ sd ~, hh*4").bank("RolandTR808")
const drumsFull  = s("bd*2 [sd bd] sd [bd*2], hh*8, ~ cp").bank("RolandTR808")
const bajo       = note("*4").s("sawtooth").lpf(600)
const arpegio    = n("0 2 4 7 9 7 4 2").scale("C4:minor").s("triangle").room(0.4)

// arrange() recibe pares [cantidadDeCiclos, patron]:
arrange(
  [2, arpegio],                               // Intro (2 ciclos: solo arpegio)
  [4, stack(drumsSuave, bajo)],               // Verso (4 ciclos: batería suave + bajo)
  [4, stack(drumsFull, bajo.lpf(1400), arpegio)] // Drop/Coro (4 ciclos: todo junto)
)

4. Ritmos Euclidianos, Polimetría y Canon (.off y .iter)

Si te interesa explorar ritmos complejos de forma muy simple:

  • Ritmos Euclidianos (pulsos, pasos, rotación): Distribuyen pulsos de la manera más equitativa posible dentro de pasos. Por ejemplo, "bd(3,8)" genera el clásico tresillo/clave de tresillo habanero / reggaetón / dancehall, y "cp(5,16)" genera la clave de bossa nova.
  • .off(tiempo, fn): Crea una copia del patrón desplazada en el tiempo y le aplica una transformación (por ejemplo, subir una quinta justa con .add(7) o una octava con .add(12)), creando cánones y armonías instantáneas.
  • .iter(n): Rota el punto de inicio del patrón en cada ciclo, generando variaciones rítmicas hipnóticas.
stack(
  // Polirritmia euclidiana: 3 en 8 contra 5 en 16
  s("bd(3,8), cp(5,16), hh(7,8,1)").bank("RolandTR909").gain(0.8),
  // Canon melódico con .off(): la copia suena 1/8 de ciclo después y una 5ta más arriba
  n("0 2 4 6").scale("C4:dorian").s("sawtooth").lpf(1200)
    .iter(4)
    .off(1/8, x => x.add(4).lpf(2500).gain(0.65))
    .room(0.4)
)

5. Visuales Reactivos (Hydra), MIDI y Conexión Externa

Strudel no solo produce sonido en el navegador; también puede dibujar visualizaciones en tiempo real y comunicarse con otros programas o sintetizadores físicos:

  • Visualizadores integrados: Añade .pianoroll(), ._scope() (osciloscopio), ._spiral() o ._pitchwheel() al final de cualquier patrón para ver la música dibujada dentro del código.
  • Hydra (Sintetizador de Video en Vivo): En strudel.cc puedes escribir await initHydra() arriba de tu código y programar visuales psicodélicos con funciones como osc(10, 0.1, 1.2).kaleid(4).out() que reaccionan a tus patrones de Strudel con H(patron).
  • Salida y Entrada MIDI (.midi()): Si conectas un sintetizador por USB o abres un puerto MIDI virtual hacia Ableton Live, Reaper, Bitwig o VCV Rack, basta con agregar .midi('NombreDeTuDispositivo') a tu patrón de notas para que Strudel sea el secuenciador de tu estudio.
// Prueba los visualizadores integrados directamente aquí:
note("c3 eb3 g3 bb3 c4 bb3 g3 eb3")
  .s("sawtooth")
  .lpf(sine.range(400, 2400).slow(2))
  ._pianoroll({ labels: 1 })
