La escena del live coding

Traducido como programación en vivo. Puede ser tanto de música como de visuales. Se utiliza a menudo en las algoraves.

Algoraves

Algoritmo + raves. Evento en que gente baila con música generada a partir de algoritmos, generalmente hechos con live coding. Puede tener diversos estilos.

Vamos a Strudel

Para esta sección, puede ser útil revisar el repaso en la documentación.

Sonidos y bancos

$: sound("casio")           // selecciona sonido o sample por nombre
_$: sound("casio:2")        // selecciona número de sonido/sample
_$: sound("bd hh sd oh")
_$: sound("bd hh sd oh").bank("RolandTR909")  // banco de baterías
_$: sound("bd:6 bd:6 [~ bd:6] [bd:6 bd:6]")  // sub-secuencia
_$: sound("hh hh hh [hh [hh hh hh]]")        // sub-sub-secuencia

Mini-notation

SímboloQué hace
[ ]Subdividir la secuencia
- o ~Silencio
*Multiplicar (más rápido)
/Dividir (más lento)
@Alargar duración
!Replicar
< >Un elemento por ciclo
,Sonar al mismo tiempo
 
_$: sound("hh hh hh [hh [hh*3]]")
_$: sound("bd*4")
_$: sound("bd*4, [~ ]*2, [~ hh]*4")
  .bank("RolandTR909")

Notas

_$: note("c e g b")              // notación americana
_$: note("0 2 4 6").scale("c:major") // grados de la escala
_$: note("c3 e3 g3 b3")         // especificando octava
_$: note("c3 e#3 g#3 b3")       // sostenidos y bemoles
_$: note("48 52 55 59")          // notas del piano como números
_$: note("48.5 52.3 55.1 59.9") // microtonalidad

Notas y mini-notation

_$: note("c e g b/2")         // ralentizar con /
_$: note("[c e g b]/2")       // ralentizar el arpegio a la mitad
_$: note("c e  b")       // <> alterna un elemento por ciclo
_$: note("")         // una nota por ciclo
_$: note("c e@2 g")           // @ alarga duración
_$: note("c e!2 g")           // ! replica la nota
_$: note("c e g b*2")         // * multiplica velocidad
_$: note("c e@2 [[g b] ]") // mezclamos conceptos

Acordes

_$: note("c, e, g, b")           // , para sonar varios al mismo tiempo
_$: note("<[c, e, g, b] [g, b, d, f]>") // un acorde por ciclo
_$: note("c e, g b")             // dos por ciclo al mismo tiempo
_$: chord("").voicing().room(.5)

Efectos

Para usar efectos, se ponen luego del bloque con .función().

FunciónQué hace
lpf()Low pass filter (oscurece)
hpf()High pass filter (adelgaza)
vowel()Filtro formante de vocal
gain()Volumen / dinámica
delay()Eco
room()Reverberación
pan()Paneo estéreo
speed()Velocidad / tono del sample
fast() / slow()Tempo del patrón
hush()Silencia el patrón
 
_$: note("c e g b d").room(2)
_$: note("c e g b d").room(".2 1 3 5") // parámetros que cambian por ciclo
_$: note("c e g b d").delay(.5)
_$: sound("bd*4").room(.2).delay(sine)
_$: sound("bd*4").room(.2).lpf(sine.range(100, 2000))

꩜ Desafío: Creación final

Hacé una creación que tenga batería, melodía, bajo y acordes donde se apliquen efectos y mini-notation.

  1. Seteá los ciclos por minuto con setcpm()
  2. Usá $: para cada capa de sonido
  3. Aplicá al menos dos efectos distintos
setcpm(120/4)

// --- BATERÍA ---
$: sound("bd*4, [~ sd]*2, hh*8").bank("RolandTR909")

// --- MELODÍA ---
$: note("").sound("piano")

// --- BAJO ---
$: note("c2*4").sound("sawtooth").lpf(800)

// --- ACORDES ---
$: chord("").voicing().room(.4).gain(.6)
